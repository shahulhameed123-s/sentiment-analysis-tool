 Sentiment Analysis Tool

 Overview

This project is a Machine Learning based Sentiment Analysis Tool that classifies text into:

* Positive
* Negative
* Neutral

The tool can analyze:

* Movie Reviews
* Product Reviews
* Restaurant Reviews
* Social Media Posts

 Technologies Used

* Python
* Pandas
* NLTK
* Scikit-Learn
* TF-IDF Vectorization
* Logistic Regression / Naive Bayes

 Dataset

* IMDb Movie Review Dataset
* Custom Neutral Review Samples

 Features

* Text preprocessing
* Stopword removal
* Stemming
* TF-IDF feature extraction
* Sentiment prediction

 Installation

```bash
pip install -r requirements.txt
```

 Run

Open the notebook and execute all cells.
